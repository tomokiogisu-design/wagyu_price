# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
### リモートリポジトリはgithubなどネット上の保管庫で、ローカルリポジトリは自分のPC上のデータ保管庫みたいなもの


## プッシュとマージの違いは何でしょうか？
### プッシュはローカルリポジトリからリモートリポジトリに反映させることで、マージは切り出されたブランチからメインブランチに変更を反映させること


## コミットとプッシュの違い
### コミットがステージングされた変更を確定させることで、プッシュはその変更をリモートリポジトリに反映させること


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
### '〇〇を変更'と変更内容を分かりやすく書くことが大切


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
### どちらとも切り出されたブランチからメインのブランチに変更を反映させることだが、プルリクエストはリモートリポジトリでのマージになるので責任者が確認することが大切


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
### どちらの変更を採用するのか、また合わせる場合はどこを合わせるのか適切に判断する必要がある
